# Video Recommendation Engine

A small backend service, written in Python, that recommends related videos. It models
users and videos as a **graph**, uses **BFS** and **DFS** traversal to find related
videos, and serves results through a **REST API** (FastAPI) with an **in-memory TTL/LRU cache**.

> The demo data in `data/watch_history.json` is **synthetic** (generated by
> `scripts/generate_data.py`): 2,000 sample users, 1,000 sample videos, ~52,000 watch events.

## How it works

- **Graph:** every user and every video is a node. If a user watched a video, the two
  nodes are connected. Two videos are related when the same users watched both.
- **BFS (`algo=bfs`):** explores layer by layer from a video, so the closest relatives come
  first. Videos watched by many of the same users score highest.
- **DFS (`algo=dfs`):** follows long chains of viewing behaviour, reaching videos further
  away for discovery. Results are ranked by popularity.
- **Cache (`app/cache.py`):** each result is stored for 5 minutes (TTL) and at most 1,000 results
  are kept; when full, the least recently used one is dropped (LRU). Repeat requests skip graph traversal.
  The cache lives inside the process, so it is not shared between multiple server processes.

## Setup

Requires Python 3.10+. No database or other server is needed.

```bash
python -m venv .venv
.venv\Scripts\activate          # Mac/Linux: source .venv/bin/activate
pip install -r requirements-dev.txt
uvicorn app.main:app --port 8000
```

Open http://localhost:8000/docs to try the API in the browser.

| Endpoint | What it does |
|---|---|
| `GET /recommendations/{video_id}?algo=bfs&limit=5` | Related videos (`algo` = `bfs` or `dfs`) |
| `GET /recommendations/{video_id}?use_cache=false` | Same, but skips the cache (used for benchmarking) |
| `GET /health` | Service status and cache hit/miss counts |

## Run the tests

```bash
pytest
```

## Measure the cache

With the service running: `python scripts/benchmark.py`

### Results (my machine)

| | Average response time (100 requests) |
|---|---|
| Without cache | 16.46 ms |
| With cache | 1.42 ms |
